# 🎬 Movie Explorer
 live link :- movie-explorer-gamma-smoky.vercel.app

A React + Vite movie search application powered by the OMDb API.

## Features

- Search movies
- Movie details page
- Responsive UI
- React Router
- Modern card design

## Tech Stack

- React
- Vite
- React Router
- CSS
- OMDb API
